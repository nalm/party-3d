# 축별 코딩 루브릭

> 문서 버전 0.1 · 2026-07-30 작성
> 상위 문서: `docs/framework-spec.md` (충돌 시 명세 우선)
> 상태: **초안. 파일럿 코딩으로 검증 전.**

---

## 0. 이 문서가 필요한 이유

프레임의 완성도는 좌표축이 아니라 **운영화 규칙**에서 나온다. 루브릭 없이 편집국에 3축 프레임을 배포하면 기자마다 감각으로 정당을 배치하게 되고, 그 순간 "왜 이 정당이 저기 있느냐"는 공격에 방어 논리가 없어진다.

이 문서의 목표는 하나다. **같은 정당을 두 사람이 독립적으로 코딩했을 때 비슷한 값이 나오게 하는 것.** 그리고 그 값이 어떤 증거에서 나왔는지 제3자가 추적할 수 있게 하는 것.

### 0.1 언제 이 루브릭을 쓰는가

| 상황 | 조치 |
|---|---|
| CHES · V-Party에 값이 있다 | **그 값을 쓴다.** 루브릭 코딩 불필요 |
| 값이 없다 (한국·일본·미국 등) | 루브릭 코딩 |
| 값이 있으나 시점이 오래됐다 | 기존 값을 유지하고 새 연도를 별 레코드로 추가 |

루브릭 코딩은 **기존 데이터셋을 대체하는 것이 아니라 공백을 메우는 것**이다.

### 0.2 비교 가능성 경고 (중요)

이 루브릭으로 산출한 Z축 값은 **V-Party의 `v2xpa_antiplural`과 같은 측정 도구가 아니다.** 척도 범위(0–1)만 같고 측정 모형이 다르다.

따라서:

- `src`를 `OhmyNews.rubric-v1`로 기록한다. `VParty`로 표기하지 말 것
- 같은 그래프에 두 출처의 값을 섞을 때는 **반드시 시각적으로 구분**한다
- "국민의힘 0.62는 Fidesz 0.88보다 낮다" 같은 직접 비교는 하지 않는다. 도구가 다르다

## 1. 일반 원칙

1. **증거 없는 점수는 없다.** 모든 지표 점수에는 인용 가능한 증거가 최소 1건 붙는다.
2. **인상 평가 금지.** "전반적으로 강경해 보인다"는 근거가 아니다.
3. **연도를 고정한다.** 코딩 단위는 정당-연도다. 관측 기간을 명시하고 그 기간의 증거만 쓴다.
4. **모든 정당에 같은 절차를 적용한다.** 한 정당만 코딩해 발표하지 않는다. 최소한 주요 경쟁 정당을 함께 코딩해 같이 공개한다.
5. **지표 점수를 공개한다.** 축 총점만 발표하지 않는다. 하위 지표 내역과 증거 로그를 함께 공개한다.
6. **모르면 결측이다.** 증거가 없으면 추정하지 말고 `null`로 두고 이유를 적는다.

## 2. 증거 위계

높은 등급의 증거가 있으면 낮은 등급으로 대체하지 않는다.

| 등급 | 증거 유형 | 비고 |
|---|---|---|
| A | 강령 · 당헌 · 공식 정책 문서 | 가장 강함 |
| A | 국회 표결 기록 | 행위 증거 |
| A | 발의 법안 · 당론 채택 문서 | |
| B | 당 대표 · 원내대표 · 대변인의 공식 발언 | 지도부 수준 |
| B | 당 공식 논평 · 보도자료 | |
| C | 개별 의원의 공개 발언 | 지도부 제지 여부를 함께 기록 |
| D | 언론의 해석 · 논평 | **증거로 쓰지 않는다.** A~C를 찾는 단서로만 사용 |
| — | 지지자 · 외부 단체의 행동 | 3.4절 참조 |

### 2.1 지지자 행동의 귀속 규칙

지지자나 외부 단체(유튜버, 종교 단체 등)의 행동은 **그 자체로 정당 점수가 되지 않는다.** 다음 중 하나가 확인될 때만 정당에 귀속한다.

- 당 지도부가 그 행동을 명시적으로 옹호·정당화했다 (B등급 증거 필요)
- 당이 공식적으로 연대·후원 관계를 인정했다
- 당 지도부가 제지 요구를 받고도 반복적으로 거부했다

**이 규칙은 양방향으로 엄격히 적용한다.** 특정 진영에만 느슨하게 적용하면 루브릭 전체의 신뢰가 무너진다.

## 3. X축 — 경제 (0 = 재분배 · 국가 개입, 10 = 시장 · 민영화)

지표 4개를 각각 0–10으로 코딩하고 평균한다.

### X-1. 조세 · 복지 지출 확대 입장

| 점수 | 기준 |
|---|---|
| 0 | 보편 복지 대폭 확대 + 누진 강화 + 부유세·자산과세 신설을 강령에 명시 |
| 2.5 | 복지 확대와 증세를 함께 주장하나 대상을 제한 |
| 5 | 현 수준 유지. 선별 복지 확대를 증세 없이 |
| 7.5 | 감세를 우선하고 복지는 선별·효율화 |
| 10 | 대규모 감세 + 복지 지출 억제를 강령에 명시 |

증거: 강령 복지·조세 항목, 예산안 표결, 세법 개정안 발의 내역

### X-2. 노동시장 규제 강도

| 점수 | 기준 |
|---|---|
| 0 | 해고 요건 강화, 비정규직 사용 제한, 노조권 확대를 명시 |
| 5 | 현행 유지 |
| 10 | 유연화 · 해고 요건 완화 · 파견 확대를 명시 |

증거: 노동법 개정안 표결, 강령 노동 항목

### X-3. 공공부문 · 민영화 입장

| 점수 | 기준 |
|---|---|
| 0 | 재국유화 또는 공공부문 확대 |
| 5 | 현행 유지 |
| 10 | 주요 공기업 민영화를 명시 |

### X-4. 재벌 · 대기업 규제

| 점수 | 기준 |
|---|---|
| 0 | 지배구조 강제 개편, 순환출자 금지, 분리 명령 등 구조적 규제 |
| 5 | 현행 공정거래 틀 유지 |
| 10 | 규제 완화 · 기업 자율 강조 |

### 3.5 한국 적용 시 주의

한국 보수정당의 경제축은 **강령과 집행이 자주 어긋난다.** 2012년 새누리당은 '경제민주화'와 복지 확대를 강령에 채택했다. 미 공화당 2000년 강령은 우파였으나 부시 행정부는 메디케어 파트 D를 통과시켰다.

→ **강령 코딩(A등급)과 표결·집행 코딩(A등급)이 2점 이상 벌어지면 두 값을 모두 기록**하고 어느 쪽을 채택했는지 명시한다.

## 4. Y축 — 사회 · 문화 (0 = GAL, 10 = TAN)

### 4.1 하위 차원 구성

| 대상 | 하위 지표 | 기본 가중치 |
|---|---|---|
| 공통 | Y-1 젠더 · 소수자 권리 | 1/3 |
| 공통 | Y-2 전통가치 · 종교 결합 | 1/3 |
| 비한국 | Y-3 이민 · 다문화 수용 | 1/3 |
| **한국** | **Y-4 대북 · 안보** | **1/3** (Y-3 대체) |

한국에서 Y-3(이민)을 Y-4(대북)로 대체하는 근거: 한국의 지배적 균열은 대북 태도이며, 이것이 사회계급과 거의 직교한다(Durrer de la Sota & Gethin 2021, WID WP 2021/06). 이민은 아직 정당 경쟁 축으로 작동하지 않는다.

**하위 지표 내역은 반드시 함께 공개한다.** 민주당은 "대북 포용 + 젠더 보수"라는 조합이 가능하고 실제로 그런 양상이 나타났다. 총점만 발표하면 이 정보가 사라진다.

### Y-1. 젠더 · 소수자 권리

| 점수 | 기준 |
|---|---|
| 0 | 차별금지법 · 동성혼 · 할당제를 강령에 명시하고 발의 |
| 2.5 | 원칙적 지지, 입법 우선순위는 낮음 |
| 5 | 언급 없음 또는 당내 이견으로 당론 부재 |
| 7.5 | 반대 입장을 표명하나 강령에는 없음 |
| 10 | 반대를 강령에 명시. 반페미니즘을 동원 자원으로 사용 |

증거: 차별금지법 표결·발의, 강령 성평등 항목, 선거 공보

### Y-2. 전통가치 · 종교 결합

| 점수 | 기준 |
|---|---|
| 0 | 정교분리 · 세속주의를 명시 |
| 5 | 종교 세력과 특별한 관계 없음 |
| 7.5 | 특정 종교 조직의 조직적 지지를 받고 정책에 반영 |
| 10 | 종교적 도덕을 입법 근거로 명시 |

### Y-3. 이민 · 다문화 수용 (비한국)

| 점수 | 기준 |
|---|---|
| 0 | 이민 확대 · 난민 수용 · 다문화주의 명시 |
| 5 | 현행 유지 |
| 10 | 이민 대폭 축소, 토착주의(nativism) 서사를 강령에 명시 |

Mudde(2007)의 토착주의 정의: "국가는 토착 집단만이 거주해야 하며 비토착 요소는 동질적 민족국가에 근본적 위협"이라는 이념. 단순한 이민 관리 강화와 구분할 것.

### Y-4. 대북 · 안보 (한국)

| 점수 | 기준 |
|---|---|
| 0 | 교류 · 경제협력 우선, 제재 완화 주장 |
| 2.5 | 대화 우선이나 조건부 |
| 5 | 병행. 당론 명확하지 않음 |
| 7.5 | 억제 · 제재 우선, 대화는 비핵화 이후 |
| 10 | 강경 일변도. 반공주의를 국내 정치 동원에 사용 |

**주의:** 10점 구간의 "국내 정치 동원" 요소는 Z-2(경쟁자 정당성 부정)와 겹칠 수 있다. 국내 경쟁자를 북한과 동일시하는 발언은 **Z-2에서 코딩하고 Y-4에서는 중복 계산하지 않는다.** 이중 계산은 루브릭의 흔한 실패다.

## 5. Z축 — 민주주의 규범 (0 = 다원주의, 1 = 반다원주의)

### 5.1 지표

Levitsky & Ziblatt(2018)의 권위주의 행태 4대 리트머스 테스트. Juan Linz(1978)를 발전시킨 것이며 V-Party 반다원주의 지수의 구성 요소와 거의 일치한다.

각 지표를 **0–3 순서 척도**로 코딩한다.

| 점수 | 수준 |
|---|---|
| 0 | 위반 증거 없음 |
| 1 | 개별 인물의 산발적 발언 (C등급). 지도부가 제지하거나 거리를 둠 |
| 2 | 지도부 수준의 반복적 발언 (B등급). 또는 당론에 근접 |
| 3 | 공식 당론 · 강령 · 제도적 행위 (A등급) |

### Z-1. 민주적 게임 규칙 거부

**질문:** 선거 결과와 헌정 절차를 수용하는가.

| 점수 | 예시 기준 |
|---|---|
| 0 | 패배한 선거 결과를 승복. 절차 우회 시도 없음 |
| 1 | 개별 인물이 부정선거를 주장하나 지도부가 선을 그음 |
| 2 | 지도부가 부정선거 의혹에 반복적으로 동조하거나 부인하지 않음 |
| 3 | 부정선거론을 당론·강령으로 채택. 또는 헌정 절차 우회를 실행 |

### Z-2. 정치 경쟁자의 정당성 부정

**질문:** 경쟁자를 정당한 상대로 인정하는가, 실존적 위협·범죄자·외세 앞잡이로 규정하는가.

| 점수 | 예시 기준 |
|---|---|
| 0 | 정책 비판에 한정 |
| 1 | 개별 인물의 산발적 낙인 발언 |
| 2 | 지도부가 반국가세력 · 내란세력 · 외세 추종 등의 규정을 반복 사용 |
| 3 | 경쟁 정당의 해산 · 배제를 당론으로 추구 |

**대칭 적용 필수.** 이 지표는 어느 진영에서도 나올 수 있다. 한쪽의 규정만 코딩하고 다른 쪽을 넘기면 루브릭이 무기가 된다.

### Z-3. 폭력 용인 · 조장

**질문:** 정치 폭력을 배격하는가.

| 점수 | 예시 기준 |
|---|---|
| 0 | 명확히 규탄 |
| 1 | 개별 인물이 옹호하나 지도부가 규탄 |
| 2 | 지도부가 규탄을 회피하거나 "이해할 만하다"는 식으로 완화 |
| 3 | 지도부가 저항권 · 정당한 항쟁으로 옹호 |

**2.1절 귀속 규칙을 엄격히 적용한다.** 지지자의 폭력 자체가 아니라 **당 지도부의 대응**을 코딩한다.

### Z-4. 상대의 시민적 자유 축소 의향

**질문:** 언론 · 사법 · 시민사회의 독립을 존중하는가.

| 점수 | 예시 기준 |
|---|---|
| 0 | 독립 존중. 비판 언론에 대한 제도적 압박 없음 |
| 1 | 개별 인물의 위협 발언 |
| 2 | 지도부가 특정 언론 · 판사를 표적화. 인사·예산을 통한 압박 시도 |
| 3 | 언론 규제 · 사법 구성 변경을 제도적으로 실행 |

### 5.2 총점 산출

```
Z = (Z1 + Z2 + Z3 + Z4) / 12
```

범위 0–1. 명세 5.5절의 구간에 대응시킨다.

| Z | 구간 |
|---|---|
| 0.00 – 0.30 | 다원주의 |
| 0.30 – 0.50 | 경계 |
| 0.50 – 1.00 | 반다원주의 |

단순 합산을 쓰는 이유는 가중치를 정당화할 근거가 없기 때문이다. **다만 Z-1과 Z-3에서 3점이 나오면 총점과 무관하게 별도 경보로 기록한다.** 선거 결과 불복과 폭력 옹호는 다른 지표로 상쇄될 수 있는 성질이 아니다.

### 5.3 가장 어려운 판정 — 개인 행위의 정당 귀속

대통령이나 당 대표 개인의 행위를 정당 점수로 귀속할지가 실무에서 가장 논쟁적이다. 원칙:

- **당직자로서의 행위**는 귀속한다
- **공직자로서의 행위**는 당이 사후에 옹호·추인했는지로 판단한다
- 판단이 갈리면 **두 값을 모두 기록**하고(귀속 시 / 미귀속 시) 어느 쪽을 채택했는지 명시한다

이 판정을 숨기지 말 것. 공개하면 논쟁이 되지만, 숨기면 신뢰를 잃는다.

## 6. 태그 코딩

### 6.1 포퓰리즘 태그

Mudde의 정의: "순수한 인민 대 부패한 엘리트"로 사회를 나누는 얇은 이념(thin-centered ideology). Norris는 이를 정당 가족이 아니라 좌우 전반에서 채택 가능한 **수사**로 다룬다.

| 값 | 기준 |
|---|---|
| `right` | 인민–엘리트 구도 + 그 엘리트를 문화적 · 외래적 존재로 규정 |
| `left` | 인민–엘리트 구도 + 그 엘리트를 경제적 기득권으로 규정 |
| `none` | 인민–엘리트 이분 구도가 수사의 중심이 아님 |

**Z축과 독립적으로 코딩한다.** 포퓰리즘 태그가 붙었다는 사실이 Z 점수에 영향을 주어서는 안 된다. Medzihorsky & Lindberg(2023)의 발견이 이 분리의 근거다.

한국 적용 참고: Jung(2025)은 2012–2022년 양당 5만 2천여 성명 분석에서 **양당 모두 포퓰리즘 수사가 증가**했고 특히 선거기와 야당일 때 강해진다고 보고했다. 양당 모두 태그가 붙을 수 있다.

### 6.2 조직 레이어

| 필드 | 값 | 판정 기준 |
|---|---|---|
| `institutionalization` | high / mid / low | 당 역사 길이, 지역 조직 밀도, 지도자 교체 후 존속 여부 |
| `personalization` | high / mid / low | 당명·강령이 특정 인물에 결부되는 정도, 인물 부재 시 존속 가능성 |
| `type` | mass_program / cartel_dominant / movement / personalist | 아래 표 |

| | 개인화 낮음 | 개인화 높음 |
|---|---|---|
| **제도화 높음** | `mass_program` | `cartel_dominant` 또는 `personalist` |
| **제도화 낮음** | `movement` | `personalist` |

**미해결 문제:** high/high 칸이 두 가지 다른 것을 섞는다. 국가자원 의존형 카르텔 정당(Fidesz, 자민당)과 고도로 제도화된 인물 정당(RN)이 같은 칸에 들어간다. 현재는 `type`을 별 필드로 두어 구분하되, 명세 6.3절 개정이 필요하다.

## 7. 코딩 절차

### 7.1 인원과 순서

1. **독립 코딩.** 코더 2명이 서로의 결과를 보지 않고 코딩한다
2. **불일치 확인.** 0–10 척도에서 2점 이상, 0–3 척도에서 1점 이상 차이가 나면 조정 대상
3. **조정 회의.** 증거를 놓고 합의한다. 합의 실패 시 제3 코더가 판정
4. **검토.** 코딩에 참여하지 않은 1명이 증거 로그와 점수의 일치를 확인
5. **기록.** 최종값 + 증거 로그 + 불일치 이력을 저장

### 7.2 신뢰도 기준

순서 척도에 Krippendorff의 알파를 산출한다.

| 알파 | 조치 |
|---|---|
| ≥ 0.80 | 통과 |
| 0.67 – 0.80 | 조건부 통과. 해당 지표의 기준 문구를 보강 |
| < 0.67 | **발표 불가.** 루브릭 재작성 후 재코딩 |

파일럿 단계에서 알파가 낮게 나오는 지표는 대개 기준 문구가 모호한 것이다. 코더를 바꾸기 전에 문구를 고친다.

### 7.3 전문가 서베이 대안

문서 코딩 대신 전문가 서베이로 갈 수도 있다. 두 방식은 배타적이지 않고, **문서 코딩으로 기준선을 만들고 서베이로 검증**하는 조합이 가장 강하다.

서베이 설계 시 최소 요건:

- 정치학 전공 연구자 30명 이상. 소속 · 세부전공 분포를 공개
- 축별 정의문과 앵커를 문항에 그대로 제시
- 응답자 간 분산을 함께 공개. 평균만 발표하면 이견을 숨기는 것이 된다
- 응답자의 정치적 성향을 묻고, 성향별 하위집단 평균을 비교해 보고

이것은 **오마이뉴스 단독 자산이 될 수 있는 지점**이다. 국내에 정당 위치를 체계적으로 측정한 공개 데이터가 사실상 없다.

## 8. 증거 로그 형식

지표 점수 하나당 레코드 하나. `data/evidence/{party_key}-{year}.json`에 저장한다.

```json
{
  "party_key": "kr-ppp",
  "year": 2025,
  "coding_period": ["2024-12-01", "2025-12-31"],
  "coders": ["A", "B"],
  "reviewer": "C",
  "rubric_version": "0.1",
  "entries": [
    {
      "indicator": "Z-1",
      "score_final": 2,
      "score_coder_a": 2,
      "score_coder_b": 3,
      "reconciled": true,
      "reconciliation_note": "당론 채택 여부가 불명확해 3에서 2로 하향 합의",
      "evidence": [
        {
          "grade": "B",
          "type": "지도부 공식 발언",
          "date": "2025-00-00",
          "source": "발언 원문 출처 URL 또는 문서 식별자",
          "summary": "증거 요지를 한 문장으로",
          "attribution_note": "당직자 발언. 6.3절 귀속 규칙 적용 불필요"
        }
      ]
    }
  ],
  "attribution_decisions": [
    {
      "issue": "계엄 선포를 당에 귀속할 것인가",
      "decision": "미귀속. 대통령 개인의 공직 행위로 처리하고, 당의 사후 대응만 Z-1에서 코딩",
      "alternative_score_if_attributed": 3
    }
  ],
  "krippendorff_alpha": null,
  "status": "draft"
}
```

`status`는 `draft` → `reconciled` → `reviewed` → `published` 순으로 올린다. `published` 이전 값은 앱에 노출하지 않는다.

## 9. 워크드 예시 — Z축

**아래 점수는 절차를 보여주기 위한 가안이며 증거 로그가 완성되지 않았다. 인용 금지.**

두 정당을 나란히 놓은 것은 5.1절의 대칭 적용 원칙을 보이기 위한 것이다. 한 정당만 코딩해 발표하는 것은 이 루브릭 위반이다.

| 지표 | 국민의힘 (가안) | 판정 논점 | 더불어민주당 (가안) | 판정 논점 |
|---|---|---|---|---|
| Z-1 규칙 거부 | 2 | 지도부의 부정선거론 동조 여부. 계엄은 8절 귀속 판정에 따라 미귀속 처리 | 0 | 선거 결과 수용에 이견 없음 |
| Z-2 경쟁자 부정 | 2 | '반국가세력' 규정의 당론성 여부 | 1–2 | '내란세력' 규정의 반복 사용 여부. **여기서 관대해지면 안 된다** |
| Z-3 폭력 용인 | 2 | 법원 난입 사태에 대한 지도부 대응. 2.1절 귀속 규칙 엄격 적용 | 0 | |
| Z-4 자유 축소 | 1 | 언론 · 사법 표적화의 지도부 수준 여부 | 1 | 방송 관련 입법 및 사법 비판의 성격 |
| **총점** | **7/12 = 0.58** | 반다원주의 구간 | **2–3/12 = 0.17–0.25** | 다원주의 구간 |

### 9.1 이 예시에서 드러나는 것

**첫째, 계엄의 귀속 판정이 결과를 크게 바꾼다.** 미귀속 시 Z-1은 2점, 귀속 시 3점이다. 총점은 0.58 대 0.67로 달라진다. 구간(반다원주의)은 같지만, 이 판정을 공개하지 않으면 숫자의 근거가 사라진다.

**둘째, Z-2는 양쪽에서 점수가 나온다.** 이 지표를 한쪽에만 적용하면 루브릭 전체가 정파적 도구로 읽힌다. 민주당 Z-2를 0으로 두고 싶은 유혹이 있다면, 그것이 바로 이 루브릭이 막아야 하는 편향이다.

**셋째, 명세 12절의 재분류 임계선과 연결된다.** 국민의힘 0.58은 0.50을 넘으므로 '반다원주의' 구간이다. 그러나 이것이 곧 "극우 정당"이라는 결론은 아니다. 정당 가족 기준으로는 토착주의가 약해 주류 우파에 머문다. **어떤 기준을 쓰면 어떤 판단이 나오는지를 보여주는 것**이 이 프레임의 목적이며, 단일 결론을 내리는 것이 아니다.

## 10. 금지 사항

- 인상 평가로 점수 부여
- 언론 논평(D등급)을 증거로 사용
- 지지자 행동을 2.1절 규칙 없이 정당에 귀속
- 한 정당만 코딩해 발표
- 축 총점만 발표 (지표 내역 · 증거 로그 누락)
- Y-4와 Z-2의 이중 계산
- 포퓰리즘 태그를 Z 점수에 반영
- 루브릭 버전을 올리지 않고 과거 값 소급 수정
- 알파 0.67 미만인 지표를 발표
- 이 루브릭 값과 V-Party 값을 같은 축에서 구분 없이 비교

## 11. 발표 시 필수 병기 사항

1. 루브릭 버전과 코딩 기간
2. 코더 수, 검토자 유무, Krippendorff 알파
3. 지표별 점수 내역
4. 귀속 판정 내역 (8절 `attribution_decisions`)
5. 구간 절단점(0.30 / 0.50)이 문헌 근거가 없는 제안값이라는 사실
6. 이 값이 V-Party와 다른 도구라는 사실
7. 전문가 코딩의 규범적 편향 가능성

## 12. 미해결 과제

| 과제 | 비고 |
|---|---|
| 파일럿 코딩 | 정당 4개 × 코더 2명으로 알파 산출. 이것 없이 본 코딩 진입 금지 |
| Z 지표 가중치 | 현재 균등. Z-1 · Z-3의 별도 경보 처리가 적절한지 검증 필요 |
| 구간 절단점 검증 | 0.30 / 0.50이 타당한지. 영국 보수당 0.35가 '경계'인 것이 합당한가 |
| 조직 2×2 high/high 칸 | 명세 6.3절 개정 |
| 대외 · 주권 축 | 명세 8절. 태그로 보류 중 |
| 관측 기간 표준 | 1년 / 임기 / 선거 주기 중 무엇을 단위로 할지 |
